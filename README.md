# 🏠 Airbnb Global Performance Dashboard

An interactive **Power BI dashboard** developed to analyze Airbnb's global listing performance, pricing, hosts, reviews, ratings, and city-level market trends.

## 📊 Project Overview

This project uses Microsoft Power BI to transform Airbnb data into an interactive business intelligence dashboard. The dashboard provides insights into listing growth, property types, pricing, host performance, customer ratings, and market share across different cities.

## 🛠️ Tools & Technologies

- **Power BI**
- **DAX**
- **Data Cleaning & Transformation**
- **Data Modeling**
- **Data Visualization**
- **Microsoft Excel / CSV**

## 📌 Key KPIs

- Total Listings
- Total Hosts
- Total Reviews
- Average Price
- Average Rating
- Superhost Performance
- Property Type Distribution
- City-Level Market Share

## 📈 Dashboard Features

### 🏠 Listing & Property Analysis
- Analyze Airbnb listings by property/room type.
- Track listing growth and distribution.
- Compare different property categories.

### 💰 Pricing Analysis
- Analyze average pricing across different room/property types.
- Compare pricing patterns across locations.

### ⭐ Ratings Analysis
- Analyze overall customer ratings.
- Compare Accuracy, Cleanliness, Communication, Location, and Value ratings.
- Identify differences in customer satisfaction across cities.

### 👤 Host Analysis
- Compare Superhost and non-Superhost listings.
- Analyze host performance across different locations.

### 🌎 Market Analysis
- Analyze Airbnb listing distribution across cities.
- Identify cities contributing significantly to the overall market share.

## 💡 Key Insights

- Listing growth varies across different property types.
- Superhost and non-Superhost listings show differences across cities.
- Average pricing varies significantly between room/property types.
- Airbnb market share is concentrated across key cities.
- Customer ratings vary across different rating categories and locations.
